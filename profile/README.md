# modl
modl.gg is a modern, open-source moderation and support suite built to completely streamline administration for Minecraft servers.

It combines a powerful and slick web interface with AI-driven tools to automate support tickets, manage chat reports, create web-viewable relays, and intelligently handle player punishments, allowing you to stay in control of your server from anywhere.
